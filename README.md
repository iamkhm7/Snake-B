# 🐍 Snake Game

A classic Snake Game developed using **Python and Pygame**. Control the snake, eat food to increase your score, and avoid colliding with the walls or your own tail.

This project was created to practice Python programming and explore basic game development. It also includes a standalone Windows executable (`.exe`) so users can play without installing Python separately.

## 🎮 Features

- Classic Snake gameplay
- Keyboard controls

- Collision detection
- Simple graphical interface
- Standalone Windows executable (`.exe`)

## 🛠️ Built With

- **Python** — Game logic and programming
- **Pygame** — Graphics, keyboard input, and game mechanics

## 🚀 How to Run

### Option 1: Run the Python Source Code

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Navigate to the project folder.
3. Install Pygame:
   ```bash
   pip install pygame
   ```
4. Run the game:
   ```bash
   python snake.py
   ```

### Option 2: Run the Executable

1. Download the `.exe` file from the repository's **Releases** section, if available.
2. Open the downloaded file on Windows to start playing.

The executable is intended to let users play without installing Python or Pygame separately.
